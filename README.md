# Zied Strategy Monitor

مستودع مستقل لمتابعة استراتيجية BUY واحدة من Zied-Strategy-Lab على OKX Spot، بوضع مراقبة ورقية فقط. لا توجد مفاتيح تداول ولا تُرسل أي أوامر حقيقية.

## التشغيل

1. افتح تبويب **Actions**.
2. اختر **Strategy Monitor - 5-hour live tracking**.
3. اضغط **Run workflow**.
4. اختر **Start**، ثم الاستراتيجية من القائمة، ثم الفريم المطابق للفريم المكتوب في اسم الاستراتيجية، وزوج OKX Spot USDT.
5. اضغط **Run workflow** لبدء المتابعة.

لإيقاف المتابعة: شغّل الـWorkflow نفسه واختر **Stop**. يؤدي ذلك إلى إلغاء دورة المتابعة الجارية وتحديث حالة الملف.

## آلية المتابعة

- يجلب المحرك بيانات الشموع العامة والسعر الحالي من OKX.
- يعيد استخدام تعريف الخصائص وقاعدة BUY نفسها في Strategy Lab، ويتحقق من أن الاستراتيجية ما زالت ناجحة في ذاكرة المختبر.
- Buy At هو إغلاق شمعة إشارة BUY المكتملة.
- SL = Buy At − 2 × ATR(14).
- TP = Buy At + 3 × ATR(14).
- لا يوجد Trailing Stop ولا تداول حقيقي.
- يراقب السعر كل 10 ثوانٍ، وينشر ملف الحالة إلى GitHub تقريبًا كل 60 ثانية، وكذلك فور اكتشاف دخول أو خروج.
- كل Workflow يعمل خمس ساعات ثم يطلق Workflow جديدًا بنفس الاختيار، مع استكمال الحالة من الملف نفسه.
- لا ينشئ المحرك ملفات بيانات JSON أخرى؛ ملف الحالة الدائم الوحيد هو `monitor_state.json`.

## اختيار الاستراتيجية

قائمة الاختيار في GitHub Actions هي لقطة من أفضل 20 استراتيجية ناجحة منشورة في Strategy Lab عند إعداد القائمة. يتحقق المحرك عند التشغيل من وجود الاستراتيجية ونجاحها في `data/lab_memory.json`. إذا تغيرت قائمة المختبر وأصبح الاختيار قديمًا، يجب تحديث خيارات Workflow.

## ملاحظة الصلاحيات

المستودع عام للقراءة، لكن GitHub يشترط صلاحية Write لتشغيل `workflow_dispatch` أو إيقافه. لذلك يمكن للزوار قراءة الحالة، أما التشغيل والتحكم فيتطلبان حسابًا لديه صلاحية كتابة في المستودع.
